Monitor Your Air Quality with PurpleAir's Python API (The Easy Way)

So What Is purpleair_api?

In short, it's a Python package that wraps the official PurpleAir API. PurpleAir makes hardware air quality sensors — the little devices you mount outside (or inside) your home that measure PM2.5, temperature, humidity, and a whole lot more. Their API is powerful, but talking to it directly means building your own HTTP request logic, handling pagination, and parsing JSON responses manually. This library does all of that for you.

The project is maintained by carlkidcrypto on GitHub, published on PyPI, and supports Python 3.10 through 3.14. It has CI/CD pipelines on GitHub Actions, code formatted with Black, and a solid test suite. Basically, it feels like a well-maintained, production-ready package — not a weekend hack project.

Getting Started — Installation Takes 30 Seconds

git clone https://github.com/carlkidcrypto/purpleair_api.git


cd purpleair_api


pip install .

Your First Query — Three Lines of Code

my_paa = PurpleAirAPI(your_api_read_key, your_api_write_key, your_ipv4_address)


retval = my_paa.request_sensor_data(1234)

Working with the Read API Only

my_paa = PurpleAirReadAPI(api_read_key)


retval = my_paa.request_multiple_sensors_data("name")

Real-World Use Case: Logging Data to a Database

Here's where things get practical. Say you want to log your sensor readings every 5 minutes and store them in SQLite for later analysis. Combine purpleair_api with a small scheduling script and you've got yourself a personal air quality history tracker.

Throw this on a Raspberry Pi running at home, and you've got a cheap, reliable air quality monitoring station. This is exactly what the companion repo purpleair_data_logger does — it can write to PostgreSQL, CSV, or SQLite out of the box. 🌬️

Air quality is personal. PM2.5 — fine particulate matter smaller than 2.5 micrometers — is linked to respiratory issues, heart disease, and early death. Wildfires, traffic, industrial pollution — all of it shows up in your sensor data. Having visibility into your local air quality helps you make real decisions: keep the windows closed today, run an air purifier, don't go for that jog at noon.

TL;DR

purpleair_api is a well-maintained Python wrapper for the PurpleAir API. Install it with one pip command, query your sensors in three lines of code, and build anything from a simple dashboard to a full database logging system. It's perfect for Home Assistant automations, research projects, or just satisfying your curiosity about the air you're breathing.

If you run a PurpleAir sensor at home and know a little Python, this library is the fastest path from raw data to something useful. Check it out on GitHub at github.com/carlkidcrypto/purpleair_api or grab it from PyPI with a single pip command. Your lungs will thank you. 🌬️
