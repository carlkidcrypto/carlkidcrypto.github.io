GitHub Agentic Workflows: Migrating to GPT-6.1 Sol

Carlos · October 08, 2026

Introduction

Over the past week, I completed a major infrastructure upgrade across all four of my GitHub repositories — ezsnmp, purpleair_api, purpleair_data_logger, and os-specific-runner. Every GitHub Agentic Workflow (gh-aw) has been migrated from the claude-sonnet-5 model to GPT-6.1 Sol via the GitHub Copilot provider.

This wasn't just a model swap — it touched 11 workflow files and recompiled all .lock.yml entries. Here's a breakdown of what changed, what I learned, and what this means for each project.

Why GPT-6.1 Sol?

GitHub Agentic Workflows (gh-aw) allow repository maintainers to describe CI/CD tasks in natural language. The gh-aw CLI compiles these into GitHub Actions workflow YAML files, which GitHub's Copilot infrastructure then executes.

The gpt-6.1-sol model routes through GitHub's github-copilot provider and offers:

- Faster compilation — fewer API calls per workflow

- Lower latency — 1M token context window handles complex workflows efficiently

- Simpler routing — no separate Anthropic API key needed

- Better context retention — longer conversations without losing earlier steps

What Changed in Each Repo

ezsnmp (PR #1357)

8 workflow files migrated. Also saw unit tests added for Session.set() exception propagation.

purpleair_api (PR #422)

Sphinx landing page and automated release docs CI landed this week, plus a fix for per-sensor network error isolation. gh-aw migration was the finishing touch.

purpleair_data_logger (PR #496)

gh-aw migration and full .lock.yml recompile with gh-aw v0.89.21.

os-specific-runner (PRs #286 & #287)

gh-aw migration plus a fix to add the node ecosystem for npm registry access in the coverage workflow.

Conclusion

The migration to GPT-6.1 Sol is complete across all four repos. Workflow compilation is faster, Copilot routing is simpler, and the gh-aw toolchain is current at v0.89.21.

Next up: watch for automated release notes, coverage autofix PRs, and docs improvements — all powered by the upgraded gh-aw infrastructure.
